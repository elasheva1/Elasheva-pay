# Elasheva Pay Prototype

This is a front-end demo. It includes:
- Dashboard and wallet balance
- Wallet funding flow
- Bank Transfer/Card/USSD method selection
- Payment flow
- Transaction history
- Digital receipt
- Profile screen

Important: payments are simulated. No real money is moved.

For production, connect the backend to a licensed payment provider such as Paystack or Flutterwave, verify webhooks/server-side transactions, secure authentication/PIN/OTP, and address applicable Nigerian regulatory requirements before handling customer funds.
